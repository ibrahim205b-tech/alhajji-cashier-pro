
# كاشير مطعم الحجي برو

نظام كاشير للمطاعم العراقية يعمل على أجهزة أندرويد.

## المميزات المخطط لها

- إدارة الوجبات والأسعار والتصنيفات.
- تسجيل الطلبات وحساب الإجماليات والخصومات.
- فتح الورديات وإغلاقها ومطابقة النقدية.
- حفظ سجل المبيعات والتقارير السابقة.
- الطباعة الحرارية عبر Bluetooth.
- العمل دون إنترنت.
- النسخ الاحتياطي للبيانات.
- بناء تطبيق Android APK.

## التقنيات

- Flutter
- Dart
- SQLite
- GitHub Actions
